ごみナビ 石山・南郷（大津市）

対象：石山寺1～5丁目・大平1～2丁目・石山寺辺町・平津1～2丁目・石山平津町・千町1～4丁目・
      石山千町・赤尾町・南郷1～6丁目・石山南郷町・石山内畑町・石山外畑町・南郷上山町

できること
- いちばん上に「今日・明日のごみ」を大きく表示（朝8時30分を過ぎると「明日」を大きく）
- 区分ごとの次の収集日を近い順に表示（タップで出し方のポイント）
- カレンダー：日付をタップするとその日の区分を表示
- 「これは何ごみ？」（ページのいちばん下）
  - 入力するとすぐ候補と次に出せる日が出る（ひらがな・カタカナ・少しの打ちまちがいもOK）
  - 出す日から見る／素材から考える／集積所に出せないもの（大型ごみ・家電・乾電池など）の案内
- ダークモード、ホーム画面に追加、オフラインでも表示

収集ルール（令和8年度 石山・南郷）
- 燃やせるごみ：毎週 火・金
- プラスチック製容器包装：毎週 木
- 紙ごみ：第2・4 水曜
- 燃やせないごみ：第1 水曜
- かん：第1・3 月曜
- ペットボトル：第2・4 月曜
- びん（＋リチウムイオン電池）：第3 水曜
- 祝日も収集。12/31・1/1は収集なし

データを直すとき（index.html の <script> の中）
- COL        … 区分ごとの曜日（dow）と何回目か（nth）
- EXCEPTIONS … 通常と違う日（年末年始など）
- FY_END     … カレンダーの有効期限（令和8年度＝2027-03-31）
- ITEMS      … 検索できる品目。kw に呼び方を足すと見つかりやすくなる
- YOMI       … 漢字の品目のひらがな読み
- MATERIALS  … 素材から考えるガイドの中身
- 更新したら sw.js の VERSION も変えると、スマホの古いキャッシュが入れ替わる
